# Access Modifiers in Python

## Introduction

Access modifiers are used in Object-Oriented Programming (OOP) to define the **visibility and accessibility** of class members such as variables and methods.

They help enforce **encapsulation**, ensuring that data is accessed in a controlled and secure way.

👉 Goal: Control access and protect data.

---

## Purpose of Access Modifiers

### 1. Encapsulation

* Protects sensitive data
* Prevents unintended access

### 2. Controlled Access

* Defines who can access variables and methods

### 3. Modularity & Security

* Prevents unwanted modification
* Keeps data integrity intact

### 4. Flexibility

* Allows controlled sharing between classes

---

## Types of Access Modifiers

| Modifier  | Symbol   | Access Level                         |
| --------- | -------- | ------------------------------------ |
| Public    | `name`   | Accessible everywhere                |
| Protected | `_name`  | Accessible within class & subclasses |
| Private   | `__name` | Accessible only inside class         |
| Default   | None     | Same as public in Python             |

---

## 1. Public Access Modifier

### Example

```python
class Employee:
    def __init__(self):
        self.name = None  # Public attribute

    def displayName(self):  # Public method
        print("Employee Name:", self.name)

if __name__ == "__main__":
    emp = Employee()
    emp.name = "Alice"  # Accessible globally
    emp.displayName()   # Accessible globally

```

### Key Points

* Accessible from anywhere
* No restriction
* Used for general methods and attributes

---

## 2. Private Access Modifier

### Example

```python
from typing import List
class BankAccount:
    def __init__(self):
        self.__balance = 0  # Private attribute using name mangling

    # Getter to provide controlled access
    def getBalance(self):
        return self.__balance

    # Public method to deposit money
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

if __name__ == "__main__":
    # Creating an object
    acnt = BankAccount()

    # print(acnt.__balance)  #  Error: AttributeError: 'BankAccount' object has no attribute '__balance'
    print(acnt.getBalance())
```

### Key Points

* Uses `__` (name mangling)
* Not directly accessible outside class
* Access via getter/setter

---

## 3. Protected Access Modifier

### Example

```python
class Vehicle:
    def __init__(self):
        self._type = None  # Protected attribute (by convention)

    def _displayType(self):  # Protected method (by convention)
        print("Vehicle Type:", self._type)

class Car(Vehicle):
    def __init__(self):
        super().__init__()
        self._type = "Car"  # Accessible in the subclass
```

### Key Points

* Uses `_` (convention)
* Accessible in subclasses
* Not strictly enforced

---

## 4. Default Access Modifier

### Example

```python
class PackageDemo:
    def showMessage(self):  # Default access (public in Python)
        print("Default access in the same package.")

if __name__ == "__main__":
    demo = PackageDemo()
    demo.showMessage()  # Accessible
```

### Key Points
* Accessible only within classes in the same package.
* Not accessible in subclasses or classes outside the package.
* Helps in maintaining package-level encapsulation.

# Inner Classes (Nested Classes) in Python

In Python, an "inner class" usually means a class defined inside another class. This helps in logically grouping helper types that are only relevant within the outer class, improving readability and organization.

Unlike Java, Python does not enforce strict access control, and inner classes do not automatically get a reference to an outer instance. If you want the inner class to work with the outer object, you pass the outer object explicitly.

Python commonly uses the following "inner class" patterns:
- Nested Class (class inside another class)
- Local Class (class inside a function/method)
- Anonymous Behavior (usually done via lambdas or small functions)

---

## 1. Static Nested Class Equivalent in Python

Java's static nested class does not require an outer instance. In Python, a nested class is also independent by default. It can access outer class variables if referenced explicitly using the outer class name.

### Example: Nested Class Accessing Outer Class Variable

```python
class OuterClass:
    static_var = 100

    # Nested class (similar to Java static nested class)
    class StaticNestedClass:
        def display(self):
            # Accessing outer class variable explicitly
            print("Static variable:", OuterClass.static_var)

def main():
    nested_obj = OuterClass.StaticNestedClass()
    nested_obj.display()  # Output: Static variable: 100

if __name__ == "__main__":
    main()
```

**Key points:**
- Nested classes in Python do not require an outer instance.
- To access outer class variables, reference them explicitly (e.g., `OuterClass.static_var`).
- No implicit "outer reference" is maintained.

---

## 2. "Non-Static Inner Class" Equivalent Pattern in Python

Java's non-static inner class can access outer instance members directly. In Python, a nested class does not automatically get the outer object. If the inner class needs outer instance data, pass the outer instance explicitly.

### Example: Nested Class Receiving Outer Instance

```python
class OuterClass:
    def __init__(self):
        self.instance_var = 42

    class InnerClass:
        def __init__(self, outer):
            # Store reference to outer instance explicitly
            self.outer = outer

        def display(self):
            print("Instance variable:", self.outer.instance_var)

def main():
    outer_obj = OuterClass()
    inner_obj = OuterClass.InnerClass(outer_obj)
    inner_obj.display()  # Output: Instance variable: 42

if __name__ == "__main__":
    main()
```

**Key points:**
- No automatic binding to an outer object exists in Python nested classes.
- Pass and store the outer object explicitly when needed.
- This keeps dependencies visible and easy to understand.

---

## 3. Local Inner Classes (Classes inside Methods) in Python

In Python, you can define a class inside a function/method. Such a class exists only within that scope, similar to Java local inner classes.

Python local classes can directly use variables from the enclosing function due to closures, but it is still best practice to pass what you need explicitly through the constructor for clarity.

### Example: Local Class inside a Method

```python
class OuterClass:
    def outer_method(self):
        local_var = 10

        # Local class defined inside a method
        class LocalInnerClass:
            def __init__(self, x):
                # Capture local_var via constructor for clarity
                self.captured = x

            def display(self):
                print("Local variable:", self.captured)

        local_inner = LocalInnerClass(local_var)
        local_inner.display()  # Output: Local variable: 10

def main():
    outer_obj = OuterClass()
    outer_obj.outer_method()

if __name__ == "__main__":
    main()
```

**Key points:**
- Defined inside a method/function and only available within that scope.
- Useful for small helper logic that shouldn't pollute the outer namespace.
- Passing values explicitly keeps code more readable than relying on closures implicitly.

---

## 4. Anonymous Inner Class Equivalent in Python

Java anonymous inner classes are typically used for one-time custom behavior. In Python, you usually do this using:
- **Lambda functions** (short single-expression functions)
- **Inline small classes** (rare; used when multiple methods/state are needed)

### Example: Lambda for One-time Behavior

```python
def main():
    # Lambda behaves like a one-time anonymous function
    say_hello = lambda: print("Hello, World!")

    # Calling the lambda
    say_hello()  # Output: Hello, World!

if __name__ == "__main__":
    main()
```

**Key points:**
- Lambdas are best for small one-liners.
- For bigger behavior (multiple methods), define a normal class (even if small).
- In real codebases, readability is preferred over overusing anonymous constructs.

## Additional Python Topic: Nested Classes are Mostly Organizational

In Python, nested classes are mostly used for:
- Grouping helper types under a parent namespace.
- Reducing global/module-level clutter.
- Creating structured APIs (e.g., config objects, request/response schemas).

A very common real-world example is the **Meta class pattern** used in Django models:

```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    class Meta:
        db_table = "products"
        ordering = ["name"]
        verbose_name_plural = "Products"
```

Here, `Meta` is a nested class that holds configuration metadata for `Product`. It is accessed directly via `Product.Meta.db_table` without needing a `Product` instance.

Since Python is dynamic and flexible, nested classes are less about strict encapsulation and more about **organization**.

## Summary Table

| Pattern | How it Works | When to Use |
|---------|-------------|-------------|
| **Static Nested Class** | Class inside a class; no outer instance needed | Grouping helper types logically |
| **Non-Static Inner Class** | Receives outer instance explicitly via constructor | When inner class needs outer object's data |
| **Local Inner Class** | Class defined inside a method; scoped to that method | One-off helper logic inside a function |
| **Anonymous Behavior** | Lambda or inline small class returned/used once | Single-use behavior without a permanent name |
| **Meta / Config Class** | Nested class holding metadata/configuration | Django models, ORMs, structured APIs |

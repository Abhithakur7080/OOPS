# Understanding "static" in Python

Python does not have a `static` keyword like Java. However, Python provides the same ideas using **class variables**, **static methods**, and **module-level variables**. These are used when you want data or behavior to belong to the class (or module) rather than a specific object instance.

---

## Static Variables in Python (Class Variables)

In Python, a **class variable** is shared across all instances of a class. This is the closest equivalent of Java's `static` variable. It is defined directly inside the class body (outside methods).

To better understand, consider the following example:

```python
# Counter class
class Counter:
    # Class variable (shared among all objects)
    count = 0

    def __init__(self):
        # Increment shared counter whenever object is created
        Counter.count += 1

    @staticmethod
    def display_count():
        print("Count:", Counter.count)

def main():
    c1 = Counter()
    c2 = Counter()
    Counter.display_count()  # Output: Count: 2

if __name__ == "__main__":
    main()
```

Here, `count` is shared among all objects of the `Counter` class, giving output as `2`.

---

## Module-level "Static" Variables

In Python, a module is loaded once (per process), so **module variables** behave like "static globals". This is commonly used for constants and shared configuration.

---

## Static Methods in Python (`@staticmethod`)

A static method in Python is defined using the `@staticmethod` decorator. It behaves like a normal function placed inside a class, and it does **not** receive `self` or `cls` automatically.

To better understand, consider the following example:

```python
# Math Utility class
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b

def main():
    # Calling static method without object creation
    result = MathUtils.add(5, 3)

    print("Result:", result)  # Output: Result: 8

if __name__ == "__main__":
    main()
```

**Key points:**
- `@staticmethod` cannot directly access instance variables unless an object is passed explicitly.
- If you need access to the class itself, Python provides `@classmethod` (receives `cls`).

---

## Static Blocks Equivalent in Python

Python does not have "static blocks" like Java, but Python has a very important rule:

> **The class body is executed once when the class is defined.**

This means any code written directly inside a class (outside methods) runs at definition time, and can be used for one-time setup.

### Example: One-time Initialization Inside Class Body

```python
class Example:
    # This line runs once when the class is created (definition time)
    print("Class body executed (one-time initialization).")

    value = 10  # Class variable initialized once

def main():
    print("Value:", Example.value)  # Output includes class-body print, then Value: 10

if __name__ == "__main__":
    main()
```

This behaves similar to a static initialization block because it runs **once** during class definition.

---

## Interaction Between "Static" and Instance Members

A static method (in Python) does not receive `self`, so it cannot directly access instance members unless an object is provided. If you want class access, use `@classmethod`.

```python
class Example:
    def __init__(self):
        self.instance_var = 10

    @staticmethod
    def static_method():
        # Creating an instance to access instance members
        obj = Example()
        print("Instance variable:", obj.instance_var)

def main():
    Example.static_method()

if __name__ == "__main__":
    main()
```

In the above example, the static method creates an object to access the instance variable.

---

## Advantages of "Static" Members in Python

There are several benefits of using class variables and static methods:

| Advantage | Description |
|-----------|-------------|
| **Shared State** | Class variables store common values shared among all instances. |
| **Utility Functions** | `@staticmethod` is useful for helper methods grouped inside a class. |
| **Organization** | Keeps related helper methods together under one class name. |
| **One-time Setup** | Class-body execution can initialize shared resources once. |

---

As you can see, Python supports the same "static concept" even without a dedicated `static` keyword.

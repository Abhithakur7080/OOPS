# Object-Oriented Programming (OOP)

## Introduction

Object-Oriented Programming (OOP) is a programming paradigm (a style of writing code) based on the concept of **objects** which can contain both **data** and **code**. The data is represented as **fields (attributes or properties)** and the code is represented as **procedures (methods)**.

Objects are **instances of classes**, where a **class acts as a blueprint** for creating objects.

OOP mainly consists of two core concepts:

* **Class**
* **Object**

---

## Class

A **class** is a blueprint or template that defines the **properties (attributes)** and **behaviors (methods)** common to all objects of its type.

Example:

* `Car`
* `Account`
* `Customer`

---

## Object

An **object** is an instance of a class. It represents a **real-world entity** with its own **state (attributes)** and **behavior (methods)**.

Example:

* `Car1`
* `Raj's Bank Account`
* `John's Transaction`

---

# Difference Between Procedural Programming and Object-Oriented Programming

## 1. Approach

**Procedural Programming**

* Focuses on step-by-step instructions.
* Program control flows sequentially through functions.

**Object-Oriented Programming**

* Focuses on modeling real-world entities as objects.
* Combines data and behavior within objects.

---

## 2. Data Handling

**Procedural Programming**

* Data is often **globally accessible**.
* Can lead to accidental modifications.

**Object-Oriented Programming**

* Data is **encapsulated inside objects**.
* Access is controlled using methods.

---

## 3. Code Reusability

**Procedural Programming**

* Limited code reuse.
* Functions can be reused but inheritance does not exist.

**Object-Oriented Programming**

* High code reuse using:

  * **Inheritance**
  * **Polymorphism**

---

## 4. Scalability

**Procedural Programming**

* Harder to scale large applications.
* Changes may affect multiple functions.

**Object-Oriented Programming**

* Easier to scale large systems.
* New features can be added with new classes.

---

## 5. Modularity

**Procedural Programming**

* Programs are divided into functions.
* Data and logic separation is weaker.

**Object-Oriented Programming**

* Programs are divided into **classes and objects**.
* Better organization and maintainability.

---

## 6. Real-World Modeling

**Procedural Programming**

* Less aligned with real-world systems.

**Object-Oriented Programming**

* Closely models real-world entities using objects.

---

# Use Cases of Object-Oriented Programming

There are four major factors that make OOP widely used in real-world applications.

## 1. Modularity

Breaking complex problems into smaller components using classes.

Example:

* Banking system with classes:

  * `Account`
  * `Customer`
  * `Transaction`

---

## 2. Code Reusability

Existing code can be reused and extended.

Example:

```
Vehicle
   ├── Car
   └── Bike
```

---

## 3. Scalability

New features can be added easily without modifying existing code.

---

## 4. Security

Sensitive data is protected using **encapsulation**.

Example:

```
class BankAccount {
   private balance;
}
```

---

# Real-Life Analogy of OOP (Bank Example)

Consider the codebase of a **Banking System**.

### Classes

Represent entities in the bank.

Examples:

* `Account`
* `Customer`
* `Transaction`

### Objects

Instances of classes.

Examples:

* Raj's Account
* John's Transaction

### Attributes

Information related to an entity.

Examples:

* Account number
* Customer name
* Balance

### Methods

Actions that objects can perform.

Examples:

* `deposit()`
* `withdraw()`
* `transfer()`

---

# Why OOP is Better for Large-Scale Applications

Object-Oriented Programming is ideal for large applications because it provides:

### 1. Modularity

Complex systems are divided into smaller manageable components.

### 2. Code Reusability

Inheritance and polymorphism allow reuse of existing code.

### 3. Scalability

New functionality can be added without affecting existing code.

### 4. Security

Encapsulation protects sensitive data by restricting direct access.

These advantages make OOP one of the most widely used paradigms for building **large, scalable, and maintainable software systems**.

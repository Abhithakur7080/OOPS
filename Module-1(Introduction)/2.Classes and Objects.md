# Class and Object in Object-Oriented Programming

## Class

In object-oriented programming, a **Class** is a blueprint or template for creating objects. It is the logical representation that defines a set of **attributes (data)** and **methods (functions)** that the objects created from the class will have.

A class does **not occupy memory on its own**. It is essentially a definition or structure from which individual objects are instantiated.

### Example: Employee Class (Python)

```python
class Employee:
    def __init__(self):
        self.__salary = 0  # private attribute
        self.employeeName = ""  # public attribute

    # Method to set the employee name
    def setName(self, name):
        self.employeeName = name

    # Method to set the salary
    def setSalary(self, val):
        self.__salary = val

    # Method to get the salary
    def getSalary(self):
        return self.__salary
```

### Key Points

* The **Employee class acts as a blueprint** for creating employee objects.
* It contains **attributes** like `employeeName` and `__salary`.
* It contains **methods** like `setName()`, `setSalary()`, and `getSalary()`.

---

# Object

An **object** is an **instance of a class**. When an object is created from a class, **memory is allocated for it** and it stores the data defined by the class.

Objects interact with the program by calling methods and accessing attributes.

### Example: Creating Objects

```python
# Creating an object of Employee class
obj1 = Employee()

# Setting attributes of object 1
obj1.setName("Raj")
obj1.setSalary(10000)

# Creating another object
obj2 = Employee()

# Setting attributes of object 2
obj2.setName("Rahul")
obj2.setSalary(15000)

# Accessing attributes
print("Salary of " + obj1.employeeName + " is " + str(obj1.getSalary()))
print("Salary of " + obj2.employeeName + " is " + str(obj2.getSalary()))
```

### Output

```
Salary of Raj is 10000
Salary of Rahul is 15000
```

### Key Points

* A **class itself does not occupy memory**, but **objects do**.
* Each object has **separate memory allocation**.
* Objects cannot directly access the internal state of other objects.
* Multiple objects can be created from the **same class blueprint**.

# Attributes and Behaviours

## Attributes

Attributes (also called **properties or fields**) represent the **data or state of an object**.

Example from Employee class:

* `employeeName`
* `__salary`

---

## Behaviours

Behaviours (also called **methods or functions**) represent the **actions an object can perform**.

Example methods in Employee class:

* `setName()`
* `setSalary()`
* `getSalary()`

---

# Creation of an Object

Objects are created from a class to access its attributes and behaviours.

In Python, objects are automatically created in the **heap memory**, while variables act as **references to those objects**.

```python
obj1 = Employee()  # reference to heap object
```

---

# Deletion of an Object

Object destruction and memory cleanup depend on the language’s memory management model.

In Python, memory management is handled automatically using **reference counting and a garbage collector**.

```python
obj1 = Employee()

del obj1  # reference removed
# object automatically deleted when no references remain
```

---

# Stack and Heap Memory Allocation

Different programming languages manage memory differently. In Python:

* Almost all data (numbers, strings, lists, objects) are stored in **heap memory**.
* Variables act as **references pointing to objects in the heap**.
* Local references exist in **stack frames during function calls**.
* Memory cleanup is handled automatically using **reference counting and garbage collection**.

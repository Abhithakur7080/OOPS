# Attributes and Methods in Object-Oriented Programming

## Attributes

Attributes (also called **properties** or **fields**) are the **data or characteristics of an object**. They represent the **state of the object at any given moment**. Attributes are typically defined inside a class and can store different types of information related to that object.

### Example: BankAccount Attributes

Suppose we want to design a **BankAccount** class. Two important attributes could be:

* **Name** → Stores the name of the account holder (string)
* **Balance** → Stores the account balance (numeric)

Since **balance is sensitive information**, it should not be directly accessible from outside the class. In real-world systems, such attributes are usually declared as **private** to protect the data.

---

## Methods

Methods are **functions defined inside a class** that represent the **behaviour or actions** an object can perform.

Methods define **what an object can do** and they often operate on the class attributes.

### Example: BankAccount Methods

A banking system may allow the following actions:

* **Check Balance** → View the current account balance
* **Deposit** → Add money to the account
* **Withdraw** → Remove money from the account

---

# Example: BankAccount Class Implementation (Python)

```python
class BankAccount:
    def __init__(self, name, balance):
        self.__name = name  # private attribute
        self.__balance = balance  # private attribute

    # Method to set the name
    def setName(self, name):
        self.__name = name

    # Method to get the name
    def getName(self):
        return self.__name

    # Method to get the balance
    def getBalance(self):
        return self.__balance

    # Method to deposit money
    def deposit(self, amount):
        self.__balance += amount

    # Method to withdraw money
    def withdrawal(self, amount):
        if amount >= self.__balance:
            print("Insufficient amount")
            return False
        
        self.__balance -= amount
        return True
```

---

# Understanding Interaction Between Attributes and Methods

In real-world OOP systems, **attributes and methods interact continuously**.

* **Attributes store the state of the object**
* **Methods modify or access those attributes**

Often attributes are marked **private** to prevent direct access from outside the class. Methods then provide **controlled access** to these attributes.

Example:

```python
account = BankAccount("Raj", 5000)

account.deposit(1000)
print(account.getBalance())
```

Output:

```
6000
```

---

# Getters and Setters

To safely interact with private attributes, two types of methods are commonly used.

## Setters

A **setter method** updates the value of an attribute.

Example:

```python
def setName(self, name):
    self.__name = name
```

## Getters

A **getter method** retrieves the value of an attribute.

Example:

```python
def getName(self):
    return self.__name
```

These methods allow controlled access to private data.

---

# Important Points When Designing Classes

## 1. Accessing Attributes

Use **getter and setter methods** to interact with private attributes.

Example:

```python
account.getBalance()
```

---

## 2. Encapsulation

Encapsulation means **keeping attributes private and exposing controlled access through public methods**.

In Python, attributes are made private using the **double underscore convention**:

```python
self.__balance
```

Note: Python does not strictly enforce privacy but uses **name mangling**.

---

## 3. Default Values

Attributes must be initialized inside the **constructor (`__init__`)**.

Example:

```python
def __init__(self, name, balance):
    self.__name = name
    self.__balance = balance
```

---

## 4. Method Parameters

Methods can take parameters to modify object state.

Example:

```python
account.deposit(500)
```

---

## 5. Error Handling

Always validate user inputs when modifying attributes.

Example improvements:

```python
def deposit(self, amount):
    if amount <= 0:
        print("Invalid deposit amount")
        return
    self.__balance += amount
```

---

# Summary

Attributes and methods together form the foundation of **Object-Oriented Programming**.

* **Attributes** store object data.
* **Methods** define object behaviour.
* **Encapsulation** protects sensitive data.
* **Getters and setters** provide controlled access.

This design helps build **secure, modular, and maintainable software systems**.

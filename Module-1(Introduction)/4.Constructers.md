# Constructor in Python

## Introduction

A **constructor** in Python is a special method of a class that is automatically called when an object is created. It initializes the data members of the class and prepares the object for use.

In Python, the constructor is defined using the `__init__()` method. This method runs immediately after a new object is created.

---

# Example: Basic Constructor

```python
class Employee:
    def __init__(self):
        self.__salary = 5000
        self.employeeName = "John Doe"

    def setName(self, s):
        self.employeeName = s

    def setSalary(self, val):
        self.__salary = val

    def getSalary(self):
        return self.__salary


if __name__ == "__main__":
    obj = Employee()

    print("Default values initialized by the constructor:\n")
    print("Employee Name:", obj.employeeName)
    print("Salary:", obj.getSalary())
```

---

# Key Points

* The constructor method is always named `__init__`.
* It must include `self` as the first parameter.
* It does not return a value.
* Objects are created by calling the class name.
* If no constructor is defined, Python provides a default constructor.

---

# Default Constructor Behavior in Python

If no `__init__()` method is defined, Python automatically provides a default constructor that simply creates the object but does not initialize attributes.

```python
class Employee:
    pass


e1 = Employee()
print(type(e1))
```

Attributes do not exist until explicitly created.

---

# Constructor Explicitly Defined

```python
class Employee:
    def __init__(self):
        self.id = 0
        self.salary = 0.0
        self.name = None


e2 = Employee()

print("e2.id =", e2.id)
print("e2.salary =", e2.salary)
print("e2.name =", e2.name)
```

---

# Purpose of Constructor

Constructors serve several important purposes:

1. **Object Initialization** – Assign values to attributes when the object is created.
2. **Code Reusability** – Initialization logic is reused every time an object is created.
3. **Valid Object State** – Ensures the object starts in a predictable state.

---

# Types of Constructors in Python

There are mainly three types:

1. Non-parameterized Constructor
2. Parameterized Constructor
3. Copy Constructor (Manual Implementation)

---

# 1. Non-Parameterized Constructor

A constructor that takes no parameters other than `self`.

```python
class Employee:

    def __init__(self):
        print("Employee created!")
```

---

# 2. Parameterized Constructor

A constructor that takes additional arguments to initialize attributes.

```python
class Employee:

    def __init__(self, name, salary):
        self.employeeName = name
        self.salary = salary


if __name__ == "__main__":

    obj = Employee("Raj", 10000)

    print("The salary of employee named " + obj.employeeName + " is " + str(obj.salary))
```

---

# Role of `self`

`self` is a reference to the current instance of the class.

It is used to:

* Access instance variables
* Bind data to the object

Example:

```python
self.salary = salary
```

---

# 3. Copy Constructor (Manual Implementation)

Python does not have a built-in copy constructor like C++. However, we can implement it manually.

```python
import copy

class Employee:

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
        self.skills = []

    @classmethod
    def from_employee(cls, other):
        new_obj = cls(other.name, other.salary)
        new_obj.skills = other.skills.copy()
        return new_obj


emp1 = Employee("Raj", 10000)
emp1.skills.append("Python")

emp2 = Employee.from_employee(emp1)

print(emp2.name)
print(emp2.salary)
print(emp2.skills)

emp3 = copy.copy(emp1)
emp4 = copy.deepcopy(emp1)
```

# Constructor Overloading in Python

Python does not support constructor overloading like Java or C++.

However, similar behavior can be achieved using:

* Default parameter values
* Variable-length arguments (`*args`, `**kwargs`)
* Class methods

Example:

```python
class Employee:

    def __init__(self, name="Unknown", salary=0, *args, **kwargs):
        self.name = name
        self.salary = salary
        self.skills = list(args)
        self.department = kwargs.get("department")


    @classmethod
    def from_string(cls, data):
        name, salary = data.split(",")
        return cls(name.strip(), int(salary.strip()))


    @classmethod
    def intern(cls, name):
        return cls(name, 0)


    def display(self):
        print("Name:", self.name)
        print("Salary:", self.salary)
        print("Skills:", self.skills)
        print("Department:", self.department)
        print()


emp1 = Employee()
emp2 = Employee("Raj", 10000)
emp3 = Employee("Amit", 12000, "Python", "SQL", department="IT")
emp4 = Employee.from_string("Neha, 15000")
emp5 = Employee.intern("Riya")

emp1.display()
emp2.display()
emp3.display()
emp4.display()
emp5.display()
```

# Constructor Chaining in Python

Constructor chaining occurs when a child class constructor calls the parent class constructor using `super()`.

This allows reuse of initialization logic.

---

# Without Constructor Chaining

```python
class Person:

    def __init__(self, name, age):
        self.name = name
        self.age = age


class Student(Person):

    def __init__(self, name, age, roll_no):
        self.name = name
        self.age = age
        self.roll_no = roll_no


    def display(self):
        print(self.name, self.age, self.roll_no)


s = Student("Rahul", 20, 101)
s.display()
```

---

# With Constructor Chaining

```python
class Person:

    def __init__(self, name, age):
        self.name = name
        self.age = age


class Student(Person):

    def __init__(self, name, age, roll_no):

        super().__init__(name, age)

        self.roll_no = roll_no


    def display(self):
        print(self.name, self.age, self.roll_no)


s = Student("Rahul", 20, 101)
```

---

# Advantages of Constructors

* Ensures objects are properly initialized
* Improves code reuse
* Makes object creation predictable
* Supports multiple initialization patterns

# Summary

Constructors are fundamental to Object-Oriented Programming in Python. They:

* Initialize object attributes
* Ensure objects start in a valid state
* Support flexible object creation
* Enable inheritance through constructor chaining

Understanding constructors is essential for designing clean and maintainable object-oriented systems.
